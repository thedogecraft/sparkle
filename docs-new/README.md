# Sparkle Docs (Alpha)

Lightweight documentation site for the Sparkle project — combining the landing page and developer docs.

Status
--
Alpha. Work in progress. This does not replace the main documentation site.

What this is
--
- A merged docs site containing the Sparkle landing page and developer documentation.
- Built with Next.js and FumaDocs (proof-of-concept).

Getting started
--
1. Clone the repo and open the docs directory:

	git clone <repo-url>
	cd docs-new

2. Install dependencies and run locally:

	npm install
	npm run dev

Contributing
--
- Add or improve pages in this folder. Keep content clear and concise.
- Open PRs against the `main` branch and include a short description of changes.

Feedback and issues
--
File issues in the main project repository or open a discussion for broader topics.
